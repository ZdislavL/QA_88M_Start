=== Команды установки и управления пакетами (pip) ===

pip install pytest
# Устанавливает фреймворк pytest в текущее виртуальное окружение.

pip install --upgrade pip
# Обновляет менеджер пакетов pip до самой последней версии.

pip install -r requirements.txt
# Устанавливает все библиотеки и зависимости, указанные в файле requirements.txt.


=== Команды запуска тестов (pytest) ===

pytest
# Запускает прогон всех тестов во всех файлах проекта (ищет файлы вида test_*.py или *_test.py).

pytest -v
# Запуск с подробным выводом (verbose): показывает название каждого отдельного теста и статус его выполнения (PASSED / FAILED).

pytest -s
# Отключает захват вывода (stdout): позволяет видеть в консоли все сообщения print(), сделанные внутри тестов.

pytest -s -v
# Комбинированный запуск: показывает подробный список тестов (-v) И выводит все print() в консоль (-s).

pytest --version
# Показывает текущую установленную версию фреймворка pytest.
